# PhishGuard

**AI-Powered Phishing Link and Message Detector**

## About the Project

PhishGuard is a cybersecurity project aimed at helping users identify potentially fraudulent links and messages.

## Planned Features

* Phishing URL detection
* Suspicious SMS and message analysis
* Hinglish scam message detection
* Screenshot-based scam detection using OCR
* Digital arrest scam detection

## Project Status

Developed.

* HTML and CSS
